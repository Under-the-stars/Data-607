# Data-607
Communication in Data Science  and Analytics

This course covered many important aspects of data communication: from graphical excellence, to effective writing, to effectively explaining/implementing statistical and machine learning models.  A rough outline of topics in the course is as follows:

Introduction to R/RMarkdown
What makes visual plots effective
Creating effective graphics with ggplot2
Writing effectively
Communicating uncertainty
Communicating models and modeling assumptions
Communicating sensitivity and robustness
Best practices presenting (and finishing off communicating sensitivity and robustness)
Ethics in Data Science
